Reference

Before layout

  1. Y1 pinout. The HSO321S datasheet is encrypted, so pin numbers follow the usual 3225 layout. Confirm before layout; tying pin 1 high is safe either way.
  2. U3 stock. LMR33640ADDAR (C2836966) is an Extended part. LCSC showed about 2,400 in stock, but one JLCPCB snapshot showed only 6 available to order. Check the live JLC page before ordering; pre-order or consign if it is short.
  3. Codec clocking. The in-kernel dacberry400 overlay sets the codec PLL source to BCLK (clock id 2) while stating 12 MHz. Y1 feeds MCLK so a small custom overlay can select MCLK instead. First bring-up test: confirm 48 kHz playback is the right pitch.
  4. IOVDD. Runs at 3.3 V (3V3_PI) to match Pi logic. The dacberry400 overlay describes IOVDD as 1.8 V; that only names a regulator for the driver and doesn't change the hardware.
  5. Connector footprints. J2–J4 use KiCad's Phoenix MC 1,5/x-G-3,5 footprints, which the XY2500R-G copies. Check the hole positions and body outline against the Xinlaiya drawing, and keep the plug side at the board edge.
  6. Isolation clearance. Keep RGND copper and every radio-side net at least 2 mm from GND-side copper, including under U1 and T1/T2.

Net-label style: a label with the same name on any sheet is the same net, as in KiCad. Pin numbers come from each part's datasheet; check them against the KiCad symbol you use.
