This page is not served over HTTPS, so the browser will block the microphone. You can listen, but to transmit open it via https:// (e.g. tailscale serve).

iPhone tips: use headphones (wired or Bluetooth) for full volume, because iOS turns the speaker down while the mic is open. Keep this page on screen to keep listening: iOS pauses audio when the phone locks or you switch apps. Share → Add to Home Screen opens it full-screen like an app.
